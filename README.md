# BaoSys

**一个面向小型项目的多子系统平台底座。**

BaoSys 将账号、登录、权限和会话管理集中到 Manager 管理系统，为独立业务子系统提供统一的接入约定。希望帮助个人开发者和小团队减少重复搭建后台基础功能的工作，把时间放在自己的业务上。

例如，当你陆续开发管理后台、任务平台和内部工具时，可以围绕同一套账号与权限目录组织这些应用，为用户分配可进入的系统和可执行的操作，并设置登录后的默认入口。

## 项目价值

- **复用基础能力。** Manager 已提供用户管理、账号启停、权限分配、登录会话查询与撤销，以及授权变更审计，新增业务系统可以沿用这套账号管理能力。
- **让多个系统有统一入口约定。** 系统目录集中登记子系统编码、访问地址、首页与权限；共享登录按用户权限回到目标页面，或展示可访问的系统。
- **保留业务系统的独立性。** 每个子系统使用自己的前端基础路径和 API 前缀。账号与登录集中维护，业务页面、接口和数据逻辑由各子系统负责。
- **把权限落实到接口。** 区分“能进入哪个系统”和“能执行哪些操作”，由网关检查入口权限、业务服务检查接口权限，前端展示与后端授权各有职责。
- **提供可读、可改的工程起点。** 前后端分离，后端区分接口契约、业务实现与基础设施，公共安全模块按职责拆分，并提供启动、设计和开发约定文档，方便理解后继续扩展。

## 适合用在哪里

BaoSys 适合作为个人项目、小团队内部平台、多个后台工具的公共底座，也适合用来学习 Vue 与 Spring Boot 前后端分离项目中的认证、授权和模块划分。

项目保持较小的功能范围，当前权限直接分配给账号。角色、组织机构、多租户和业务数据权限尚未实现；需要这些能力时，可以根据自己的业务模型继续扩展。

## 已有能力

| 方向 | 当前实现 |
|---|---|
| 账号管理 | 用户增删改查、账号启停、权限分配、默认子系统设置 |
| 登录导航 | 共享登录页、目标页面回跳、默认首页、已授权系统列表 |
| 认证与授权 | JWT、HttpOnly Cookie、浏览器请求 CSRF 校验、系统入口及接口权限检查 |
| 会话管理 | 登录会话查询与撤销、退出登录、授权变更审计 |
| 管理界面 | Vue 管理端、中英文、主题切换 |
| 接入约定 | 系统与权限目录、独立前端路径、独立 API 前缀、公共网关与资源服务安全模块 |

**当前仓库包含 Manager 管理系统和公共模块。** 其他业务子系统需要自行开发和接入；目录中的 CAT 为预留登记项，不代表仓库已包含对应业务应用。系统配置页目前为界面骨架。

## 工程组成

| 模块 | 职责 |
|---|---|
| `baosys-common-api` | 统一响应与分页协议 |
| `baosys-common-security-core` | 安全配置、JWT 和权限基础能力 |
| `baosys-common-security-resource` | Servlet 服务的认证与接口授权 |
| `baosys-common-security-gateway` | 网关认证、入口授权和 CSRF |
| `baosys-common-password` | 密码编码与校验 |
| `baosys-manager/baosys-manager-api` | Manager 接口契约和 DTO |
| `baosys-manager/baosys-manager-service` | 业务、认证中心和数据库访问，默认 9090 |
| `baosys-manager-web` | API 网关与前端静态资源宿主，默认 8080 |
| `baosys-manager-ui` | Vue 管理端，开发服务器默认 5173 |

技术栈为 Java 17、Spring Boot、Spring Cloud Gateway、MyBatis Plus、PostgreSQL、Flyway，以及 Vue 3、TypeScript、Vite、Pinia、Arco Design。具体版本以 [pom.xml](pom.xml) 和 [package.json](baosys-manager-ui/package.json) 为准。

## 从这里开始

- [启动与部署](docs/development.md)：本地启动、必填配置、测试和打包。
- [系统设计](docs/system.md)：请求链路、认证权限、接口和数据库。
- [开发约定](docs/conventions.md)：分层、依赖、接口、数据库与文档维护规则。

首次启动需要 Java 17、PostgreSQL；开发前端还需要 Node.js，版本要求见前端 `package.json`。使用空数据库或新 schema，由 Flyway 初始化结构，并按启动文档准备签名密钥、显式启用管理员初始化。

Manager 的打包访问入口为 `/baosys-manager/`，前端开发入口为 `http://localhost:5173/baosys-manager/`。新增子系统时，从登记系统目录、配置前端基址和 API 前缀开始，再接入共享登录与接口授权。具体配置和步骤见 [启动与部署](docs/development.md)。

[查看系统目录](baosys-systems.yml)，了解子系统入口和权限的配置方式。
